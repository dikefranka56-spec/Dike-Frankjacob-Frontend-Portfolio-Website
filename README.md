A professional, dark, responsive portfolio with an Amazon-inspired charcoal-and-amber visual direction (not an Amazon copy).

## Files
- `index.html` — complete site, including CSS and JavaScript
- `README.md` — setup and publishing instructions

## Publish on GitHub Pages
1. Create a new GitHub repository, such as `dike-frankjacob-portfolio`.
2. Upload `index.html` and `README.md` into the repository root.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main` and `/(root)`, then save.
5. Wait for GitHub Pages to publish and open the generated site URL.

The project cards already link to the four live project URLs supplied by the owner. This is a frontend portfolio and does not require a backend. The listed projects are demos; do not describe demo forms or sample listings as connected to live services.
